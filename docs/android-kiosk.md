# FaceAttend Киоск — Android қолданбасы

Есік алдындағы планшет/телефон үшін: тек сканерлеу беті (`/scan`), толық экран, экран сөнбейді.
Код: `android/` (Kotlin, WebView). Сервер әдепкіде — `https://face-attent.zhastunulani.kz`.

## Жинау және орнату

```bash
cd android
# JAVA_HOME — Android Studio-ның JDK-сы
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`local.properties` (git-ке кірмейді) ішінде `sdk.dir=...` болуы керек — Android Studio өзі жасайды.

## Алғашқы баптау (құрылғыда)

1. Қолданбаны ашып, камераға рұқсат беріңіз.
2. Логотипті **8 рет** тез басыңыз → **әкімші PIN-кодын** орнатыңыз (4–8 сан).
3. Мәзір → **«Жүйеге кіру / киоскіні тіркеу»** → әкімші логинімен кіріңіз →
   сканерлеу бетінде «Бір есік (авто)» → **«Киоск ету»**.
   Киоск белгісі 180 күн сақталады; кейін әкімші аккаунтынан шығуға болады.
4. Дыбыс: қолданбада басусыз ойнайды. Құрылғының медиа дыбысын көтеріңіз.

## Жасырын мәзір (логотипті 8 рет басу → PIN)

- Сканерлеу бетін қайта жүктеу
- Жүйеге кіру / киоскіні тіркеу
- Сервер мекенжайы (тек `https://`)
- PIN-кодты өзгерту (5 қате әрекеттен кейін 1 минут бұғат)
- Экранды бекіту — Android «экранды бекіту» (басқа қолданбаға шығу мүмкін емес)
- Android баптаулары, Ақпарат, Қолданбадан шығу

Байланыс жоқ болса — қолданба өзінің экранын көрсетеді және 15 с сайын қайта қосылады;
сол экрандағы логотипті де 8 рет басып мәзірге кіруге болады.

## Құрылғы қосылғанда өзі ашылуы

Android баптаулары → Қолданбалар → Әдепкі қолданбалар → **Негізгі экран** → «FaceAttend Киоск».
Енді құрылғы қосылғанда және «Үй» батырмасын басқанда киоск ашылады.
Қайтару үшін: жасырын мәзір → Android баптаулары → негізгі экранды қайта ауыстыру.

## Толық киоск режимі (міндетті емес, тек бос құрылғыда)

Device owner ретінде тағайындалса «Артқа/Үй/Соңғы» батырмалары толық бұғатталады.
**Талап:** құрылғыда бірде-бір аккаунт (Google, Samsung) болмауы керек — әдетте зауыттық
қалпына келтіруден кейін, аккаунт қоспай баптайды.

```bash
adb shell dpm set-device-owner kz.zhastunulani.faceattend.kiosk/.KioskAdminReceiver
```

Өшіру: жасырын мәзір → «Толық киоск режимін өшіру (device owner)». Өшірмей қолданбаны жою мүмкін емес.
